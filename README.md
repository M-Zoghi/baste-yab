# بسته‌یاب — مقایسه زنده‌ی بسته‌های اینترنت ایران

مقایسه‌ی شفاف بسته‌های اینترنت اپراتورهای ایرانی بر پایه‌ی **تومان بر گیگابایت** و **تومان بر (گیگابایت × روز)** — همراه با رتبه‌بندی از به‌صرفه‌ترین به گران‌ترین، تفکیک **اینترنت همراه** و **اینترنت ثابت**، نمای کارتی و جدولی، مقایسه‌ی کنار هم، کپی سریع کد دستوری (USSD) و محاسبه‌ی ۱۰٪ مالیات بر ارزش افزوده. تمامی قیمت‌ها و مشخصات مستقیماً از منابع رسمی هر اپراتور استخراج می‌شوند و هیچ عددی به‌صورت دستی وارد نشده است.

## امکانات

- **فیلتر بسته‌های محدود و خاص (روشن به‌صورت پیش‌فرض)**: تفکیک خودکار بسته‌های **شبانه / شبانت (۲ تا ۷ صبح)**، **صبحانه / صبحانت (۶ تا ۱۲ ظهر)**، **انارستان (فقط اینترنت داخلی)**، **ویژه مشترکین جدید** و **ویژه جوانان زیر ۲۸ سال**. تمام گزینه‌ها به‌طور پیش‌فرض روشن هستند و برای حذف هر گروه کافی است کلید آن را خاموش کنید.
- **دو معیار ارزش + مالیات ۱۰٪**: جابه‌جایی سریع بین **تومان بر گیگابایت** و **تومان بر (گیگابایت × روز)**، به‌همراه کلید اعمال ۱۰٪ مالیات ارزش افزوده‌ی درگاه پرداخت.
- **نمای کارتی و جدول مقایسه + مقایسه‌ی کنار هم**: نمایش بسته‌ها در دو ستون خوانا یا جدول متراکم، و امکان انتخاب تا ۳ بسته برای مقایسه‌ی دقیق کنار هم.
- **بخش نکات مهم اپراتورها**: نمایش جزئیات خاص هر اپراتور در پایین فهرست بسته‌ها؛ از جمله تفاوت **قیمت عمومی در برابر قیمت با ورود (آپتل من)**، محدودیت اینترنت داخلی سیم‌کارت‌های **انارستان همراه اول**، بسته‌های مخصوص اپ **ایرانسل من** (با قیمت ویژه اپ) و بسته‌های مخصوص وب‌سایت **ایرانسل**.
- **شفافیت تاریخ بروزرسانی و دستور کپی فوری**: نمایش تاریخ دقیق و سن نسبی آخرین بروزرسانی برای هر اپراتور به‌همراه دستور آماده برای آپدیت سریع از داخل ایران.
- **تایپوگرافی فارسی و پوسته‌ی روشن/تاریک**: استفاده از فونت **استعداد (Estedad)** به‌صورت self-hosted با `next/font/local` (بدون وابستگی به CDN خارجی) و پشتیبانی از حالت روشن و تاریک.
- **نصب به‌صورت برنامه (PWA روی کامپیوتر و موبایل)**: پشتیبانی کامل از نصب مستقیم روی ویندوز، مک، لینوکس، اندروید و آیفون/آیپد (دکمه‌ی **«نصب اپ»** در نوار بالا) به‌همراه کش آفلاین با Service Worker.

### قیمت عمومی در برابر قیمت با ورود به حساب (آپتل)

قیمت‌های آپتل از API **عمومی** (بدون ورود) خوانده می‌شود. پس از ورود به پنل «آپتل من»، بسته‌های ویژه‌ی ۳۰ روزه با تخفیف و هدیه‌ی نصب ۵ گیگابایت نمایش داده می‌شوند که در فهرست عمومی وجود ندارند. برای حفظ یکپارچگی رتبه‌بندی عمومی، این بسته‌ها وارد جدول اصلی نمی‌شوند و نمونه‌های آن‌ها در کارت اطلاع‌رسانی **«نکات مهم اپراتورها»** پایین صفحه نمایش داده می‌شود.

## بروزرسانی داده‌ها (خودکار در برابر دستی)

- **بروزرسانی خودکار (روزانه حدود ساعت ۰۶:۴۷ به‌وقت تهران در GitHub Actions):** **سامانتل**، **آپتل**، صفحه‌ی جایگزین **همراه اول (`mci.ir`)**، **وب‌سایت ایرانسل** و **ایرانسل TD-LTE** (هر دو کاتالوگ `irancell.ir/e/products/…` از سرورهای خارج ایران هم قابل دریافت‌اند). در صورت تغییر داده‌ها، انتشار مجدد سایت روی GitHub Pages نیز بلافاصله و خودکار انجام می‌شود.
- **بروزرسانی دستی از داخل ایران:** به‌دلیل مسدودبودن یا نیاز به ورود، سرورهای **فروشگاه همراه اول (`shop.mci.ir`)**، **پنل همراه من (`my.mci.ir`)**، **اپ ایرانسل من (`my.irancell.ir`)** و **رایتل (همراه و مودم)** باید از داخل ایران تازه شوند. در ایرانسل، فقط بخش اپ دستی است و بسته‌های اپ روی بروزرسانی خودکار وب‌سایت باقی می‌مانند. تا ۱۴ روز، داده‌ی فروشگاه و پنل همراه اول بر صفحه‌ی جایگزین اولویت دارد و بسته‌های هر دو منبع با هم می‌مانند.

برای بروزرسانی هم‌زمان اپراتورهای داخل ایران از روی سیستم شخصی خودتان (اگر مخزن را با `git clone` دریافت کرده‌اید می‌توانید نتیجه را push کنید؛ در صورت دانلود ZIP، فایل‌های پوشه‌ی `src/data/providers/` را دستی در مخزن آپلود کنید):

<div dir="ltr">

```bash
git clone https://github.com/M-Zoghi/baste-yab.git
cd baste-yab
npm run update:iran
git add src/data/providers && git commit -m "data: refresh" && git push
```

</div>

> **نکته برای رایتل:** آداپتور خودش با `POST auth/authenticate` (کاربر ناشناس `website`) توکن می‌گیرد و با `Authorization: Bearer` کاتالوگ را می‌خواند؛ اگر سرور از محل اجرا در دسترس نبود (مسدودیت جغرافیایی)، با `--only rightel --input rightel.har` از فایل HAR بروزرسانی کنید.

سایر دستورات اسکریپت بروزرسانی:

<div dir="ltr">

```bash
node update/fetch-providers.mjs                                          # اجرای همه آداپتورها
node update/fetch-providers.mjs --only samantel                          # فقط سامانتل
node update/fetch-providers.mjs --only aptel                             # فقط آپتل
node update/fetch-providers.mjs --only mci --input shop.har              # همراه اول از فایل HAR یا JSON (فروشگاه یا پنل همراه من)
node update/fetch-providers.mjs --only irancell --input my.irancell.ir.har  # ایرانسل: بخش اپ از HAR (وب‌سایت خودکار تازه می‌شود)
node update/fetch-providers.mjs --only rightel --input rightel.har       # رایتل همراه + مودم از فایل HAR یا JSON
```

</div>

## راه‌اندازی روی GitHub Pages

1. مخزن را fork یا push کنید (پوشه‌ی `.github/` را حتماً حفظ کنید).
2. در مسیر **Settings → Pages** بخش **Source** را روی **GitHub Actions** قرار دهید.
3. با هر push روی شاخه‌ی `main`، گردش‌کار `Deploy to GitHub Pages` به‌صورت خودکار خروجی استاتیک (`BUILD_MODE=pages`) را می‌سازد و منتشر می‌کند.
4. اگر نام مخزن `USERNAME.github.io` نباشد، `basePath` به‌طور خودکار توسط workflow تنظیم می‌شود.

```text
src/data/providers/         ← فایل‌های JSON داده‌ی اپراتورها
public/                     ← لوگو، آیکون‌های PWA (۱۹۲، ۵۱۲، Apple) و Service Worker آفلاین (sw.js)
update/fetch-providers.mjs  ← اسکریپت استخراج و پارس داده‌ها (بدون وابستگی خارجی)
.github/workflows/          ← pages.yml (انتشار روی Pages) · update-data.yml (تازه‌سازی روزانه)
src/app/fonts/              ← فایل‌های woff2 فونت استعداد (self-hosted با next/font/local)
```

## مشارکت در تکمیل داده‌ها

مهم‌ترین کمکی که می‌توانید انجام دهید، ارسال یک فایل **HAR** از صفحه‌ی بسته‌های اپراتورهای داخل ایران (به‌ویژه مخابرات و آسیاتک؛ برای تازه‌کردن بخش اپ ایرانسل من هم می‌توانید HAR صفحه‌ی بسته‌های my.irancell.ir را بفرستید) است. راهنمای گام‌به‌گام ضبط و ارسال HAR را در [DATA.md](https://github.com/M-Zoghi/baste-yab/blob/main/DATA.md) بخوانید.
