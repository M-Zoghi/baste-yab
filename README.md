# بسته‌یاب — مقایسه زنده‌ی بسته‌های اینترنت ایران

مقایسه‌ی شفاف بسته‌های اینترنت اپراتورهای ایرانی بر پایه‌ی **تومان بر گیگابایت** و **تومان بر (گیگابایت × روز)** — همراه با رتبه‌بندی از به‌صرفه‌ترین به گران‌ترین، تفکیک **اینترنت همراه** و **اینترنت ثابت**، نمای کارتی و جدولی، ماشین‌حساب **«محاسبه نیاز من»**، مقایسه‌ی کنار هم، شماره‌گیری و کپی سریع کد دستوری (USSD) و محاسبه‌ی ۱۰٪ مالیات بر ارزش افزوده. تمامی قیمت‌ها و مشخصات مستقیماً از منابع رسمی هر اپراتور استخراج می‌شوند و هیچ عددی به‌صورت دستی وارد نشده است.

## امکانات

- **فیلتر بسته‌های محدود و خاص (روشن به‌صورت پیش‌فرض)**: تفکیک خودکار بسته‌های **شبانه / شبانت (۲ تا ۷ صبح)**، **صبحانه / صبحانت (۶ تا ۱۲ ظهر)**، **ساعتی (اعتبار چندساعته)**، **انارستان (فقط اینترنت داخلی)**، **ویژه مشترکین جدید** و **ویژه جوانان زیر ۲۸ سال** به‌همراه گزینه‌ی **پنهان‌کردن بسته‌های اختصاصی اپ (`portalOnly`)**.
- **فیلترهای ترکیبی، چیپ‌های فعال و فناوری اینترنت ثابت**: انتخاب هم‌زمان چند بازه‌ی مدت اعتبار (`۱ تا ۳ روز`، `۷ تا ۱۵ روز`، `۳۰ روزه`، `بلندمدت`)، تفکیک **مودم سیم‌کارتی (TD-LTE/5G)** از **خط ثابت (ADSL/فیبر)**، و نوار **فیلترهای فعال** بالای نتایج برای حذف تکی هر فیلتر.
- **ماشین‌حساب هوشمند «محاسبه نیاز من»**: با وارد کردن حجم و مدت مورد نیاز، به‌صرفه‌ترین تک‌بسته را با **ترکیب چند بسته** (تا ۱۲ بسته) مقایسه می‌کند و میزان صرفه‌جویی را نشان می‌دهد.
- **دو معیار ارزش + مالیات ۱۰٪ + ذخیره تنظیمات**: جابه‌جایی سریع بین **تومان بر گیگابایت** و **تومان بر (گیگابایت × روز)** و کلید اعمال ۱۰٪ مالیات ارزش افزوده، با ذخیره‌ی خودکار ترجیحات در مرورگر (`localStorage`) و همگام‌سازی همه‌ی فیلترها با نشانی اینترنتی (URL) قابل اشتراک‌گذاری.
- **نمای کارتی/جدولی، «بهترینِ هر اپراتور» و مقایسه‌ی کنار هم**: نوار خلاصه‌ی **بهترینِ هر اپراتور** در بالای نتایج، کپی و شماره‌گیری مستقیم کد دستوری (`tel:`)، و انتخاب تا ۳ بسته برای مقایسه‌ی کنار هم با دکمه‌ی **«کپی خلاصه مقایسه»**.
- **بخش نکات مهم اپراتورها**: نمایش جزئیات خاص هر اپراتور در پایین فهرست بسته‌ها؛ از جمله تفاوت **قیمت عمومی در برابر قیمت با ورود (آپتل من)**، محدودیت اینترنت داخلی سیم‌کارت‌های **انارستان همراه اول**، بسته‌های مخصوص اپ **ایرانسل من** و بسته‌های مخصوص وب‌سایت **ایرانسل**.
- **شفافیت تاریخ بروزرسانی و هشدار کهنگی داده**: نمایش تاریخ دقیق و سن نسبی آخرین بروزرسانی برای هر منبع جداگانه (`source.parts`)، دستور کپی فوری برای آپدیت از داخل ایران، و **هشدار خودکار کهنگی داده (بیش از ۷ روز)** روی منابع دستی/ترکیبی.
- **تایپوگرافی فارسی و پوسته‌ی روشن/تاریک**: استفاده از فونت **استعداد (Estedad)** به‌صورت self-hosted با `next/font/local` (بدون وابستگی به CDN خارجی) و پشتیبانی از حالت روشن و تاریک.
- **نصب به‌صورت برنامه (PWA روی کامپیوتر و موبایل)**: پشتیبانی کامل از نصب مستقیم روی ویندوز، مک، لینوکس، اندروید و آیفون/آیپد (دکمه‌ی **«نصب اپ»** در نوار بالا) به‌همراه کش آفلاین با Service Worker.

### قیمت عمومی در برابر قیمت با ورود به حساب (آپتل)

کاتالوگ پایه‌ی آپتل از API **عمومی** (بدون ورود) خوانده می‌شود. پس از ورود به پنل «آپتل من» (`my.aptel.ir`)، ۴ بسته‌ی قیمت‌دار اختصاصی با تخفیف بیشتر و یک هدیه‌ی نصب رایگان ۵ گیگابایت ۷ روزه نمایش داده می‌شوند که در فروشگاه عمومی نیستند. ۴ بسته‌ی قیمت‌دار مستقیماً با برچسب **«فروش فقط از پنل «آپتل من» / my.aptel.ir»** و لینک خرید به `my.aptel.ir/packages` وارد رتبه‌بندی اصلی می‌شوند، و هدیه‌ی نصب رایگان (به‌دلیل نداشتن امکان خرید مستقل) در کارت اطلاع‌رسانی **«نکات مهم اپراتورها»** پایین صفحه نمایش داده می‌شود.

## بروزرسانی داده‌ها (خودکار در برابر دستی)

- **بروزرسانی خودکار (روزانه حدود ساعت ۰۶:۴۷ به‌وقت تهران در GitHub Actions):** **سامانتل**، **بخش عمومی آپتل** (`www.aptel.ir`)، صفحه‌ی جایگزین **همراه اول (`mci.ir`)**، **وب‌سایت ایرانسل** و **ایرانسل TD-LTE** (هر دو کاتالوگ `irancell.ir/e/products/…` از سرورهای خارج ایران هم قابل دریافت‌اند). در صورت تغییر داده‌ها، انتشار مجدد سایت روی GitHub Pages نیز بلافاصله و خودکار انجام می‌شود.
- **بروزرسانی دستی (از داخل ایران یا نیازمند ورود):** به‌دلیل مسدودبودن جغرافیایی یا نیاز به توکن ورود، سرورهای **فروشگاه همراه اول (`shop.mci.ir`)**، **پنل همراه من (`my.mci.ir`)**، **اپ ایرانسل من (`my.irancell.ir`)**، **پنل «آپتل من» (`my.aptel.ir`)** و **رایتل (همراه و مودم)** به‌صورت دستی یا با فایل HAR تازه می‌شوند. در ایرانسل و آپتل، بخش عمومی روی بروزرسانی خودکار وب‌سایت باقی می‌ماند. تا ۱۴ روز، داده‌ی فروشگاه و پنل همراه اول بر صفحه‌ی جایگزین اولویت دارد و بسته‌های هر دو منبع با هم می‌مانند.

برای بروزرسانی هم‌زمان اپراتورهای داخل ایران از روی سیستم شخصی خودتان (اگر مخزن را با `git clone` دریافت کرده‌اید می‌توانید نتیجه را push کنید؛ در صورت دانلود ZIP، فایل‌های پوشه‌ی `src/data/providers/` را دستی در مخزن آپلود کنید):

<div dir="ltr">

```bash
git clone https://github.com/M-Zoghi/baste-yab.git
cd baste-yab
npm run update:iran
git add src/data/providers && git commit -m "data: refresh" && git push
```

</div>

> **نکته برای رایتل:** آداپتور خودش با `POST auth/authenticate` (کاربر ناشناس `website`) توکن می‌گیرد و با `Authorization: Bearer` کاتالوگ را می‌خواند؛ اگر سرور از محل اجرا در دسترس نبود (مسدودیت جغرافیایی)، با `--only rightel --input rightel.har` از فایل HAR بروزرسانی کنید.

سایر دستورات اسکریپت بروزرسانی:

<div dir="ltr">

```bash
node update/fetch-providers.mjs                                          # اجرای همه آداپتورها
node update/fetch-providers.mjs --only samantel                          # فقط سامانتل
node update/fetch-providers.mjs --only aptel                             # فقط بخش عمومی آپتل
node update/fetch-providers.mjs --only aptel --input my.aptel.ir.har     # آپتل: بخش پنل «آپتل من» از HAR (عمومی خودکار تازه می‌شود)
node update/fetch-providers.mjs --only mci --input shop.har              # همراه اول از فایل HAR یا JSON (فروشگاه یا پنل همراه من)
node update/fetch-providers.mjs --only irancell --input my.irancell.ir.har  # ایرانسل: بخش اپ از HAR (وب‌سایت خودکار تازه می‌شود)
node update/fetch-providers.mjs --only rightel --input rightel.har       # رایتل همراه + مودم از فایل HAR یا JSON
```

</div>

## راه‌اندازی روی GitHub Pages

1. مخزن را fork یا push کنید (پوشه‌ی `.github/` را حتماً حفظ کنید).
2. در مسیر **Settings → Pages** بخش **Source** را روی **GitHub Actions** قرار دهید.
3. با هر push روی شاخه‌ی `main`، گردش‌کار `Deploy to GitHub Pages` به‌صورت خودکار خروجی استاتیک (`BUILD_MODE=pages`) را می‌سازد و منتشر می‌کند.
4. اگر نام مخزن `USERNAME.github.io` نباشد، `basePath` به‌طور خودکار توسط workflow تنظیم می‌شود.

## مشارکت در تکمیل داده‌ها

مهم‌ترین کمکی که می‌توانید انجام دهید، ارسال یک فایل **HAR** از صفحه‌ی بسته‌های اپراتورهای داخل ایران (به‌ویژه مخابرات و آسیاتک؛ برای تازه‌کردن بخش اپ ایرانسل من هم می‌توانید HAR صفحه‌ی بسته‌های my.irancell.ir را بفرستید) است. راهنمای گام‌به‌گام ضبط و ارسال HAR را در [DATA.md](https://github.com/M-Zoghi/baste-yab/blob/main/DATA.md) بخوانید.
