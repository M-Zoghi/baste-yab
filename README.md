# بسته‌یاب — مقایسه زنده‌ی بسته‌های اینترنت ایران

[نسخه‌ی آنلاین → GitHub Pages](https://m-zoghi.github.io/baste-yab/) ·
[راهنمای داده‌ها (DATA.md)](DATA.md)

مقایسه‌ی بسته‌های اینترنت ارائه‌دهنده‌های ایرانی بر پایه‌ی **تومان بر گیگابایت** و **تومان بر (گیگابایت × روز)** — با رتبه‌بندی بهترین→بدترین، تفکیک **اینترنت همراه / ثابت**، نمای کارتی و جدول مقایسه، مقایسه‌ی کنار هم، کپی سریع کد دستوری (USSD) و کلید محاسبه‌ی مالیات ۱۰٪. داده‌ها مستقیماً از سایت رسمی هر ارائه‌دهنده خوانده می‌شوند؛ هیچ عددی دستی نیست.

## وضعیت ارائه‌دهنده‌ها

| ارائه‌دهنده | دسته | منبع |
|---|---|---|
| همراه اول | همراه | ✅ API فروشگاه رسمی `shop.mci.ir/api/search/v1/products?category=19` (تازه‌سازی دستی از داخل ایران) + جایگزین خودکار `mci.ir/internet-plans` (با تفکیک بسته‌های فقط داخلی انارستان) |
| ایرانسل | همراه | 🔶 JSON عمومی `irancell.ir/e/products/…` (به‌روزرسانی دستی از داخل ایران) |
| رایتل | همراه و مودم ثابت | ✅ API پورتال رسمی `portal-api.rightel.ir` (تازه‌سازی دستی از داخل ایران) |
| سامانتل | همراه (اپراتور مجازی) | ✅ API عمومی (به‌روزرسانی خودکار روزانه) |
| آپتل | همراه (اپراتور مجازی) | ✅ API عمومی `www.aptel.ir/api/ep/query?scope=public` (به‌روزرسانی خودکار روزانه) |
| مخابرات / آسیاتک / ایرانسل TD-LTE | ثابت | ⏳ در انتظار داده — [چطور کمک کنید](DATA.md) |

## امکانات

- **فیلتر بسته‌های محدود و خاص**: بسته‌های **شبانه / شبانت (۲ تا ۷ صبح)**، **صبحانت / صبح (۶ تا ۱۲)**، **انارستان (فقط اینترنت داخلی)**، **ویژه مشترکین جدید** و **ویژه زیر ۲۸ سال** به‌طور پیش‌فرض روشن هستند و با خاموش‌کردن هر کلید می‌توانید آن‌ها را از فهرست حذف کنید.
- **دو معیار ارزش + مالیات ۱۰٪**: جابه‌جایی سریع بین **تومان بر گیگ** و **تومان بر گیگ×روز** و اعمال ۱۰٪ مالیات بر ارزش افزوده‌ی درگاه پرداخت.
- **نمای کارتی و جدول مقایسه + مقایسه‌ی کنار هم**: مشاهده در دو ستون خوانا یا جدول داده‌ی متراکم، و پین‌کردن تا ۳ بسته برای مقایسه‌ی تمام مشخصات کنار هم.
- **بخش نکات اپراتورها و تاریخ آخرین بروزرسانی**: نمایش تاریخ دقیق بروزرسانی هر اپراتور (خودکار در برابر دستی) به‌همراه دستور کپی‌کردنی برای بروزرسانی آسان.
- **تایپوگرافی بهینه و پوسته‌ی روشن/تاریک**: میزبانی داخلی فونت **استعداد (Estedad)** با پشتیبان وزیرمتن — کاملاً مستقل از CDNهای خارجی.

### قیمت عمومی در برابر قیمت مشترک

قیمت‌های آپتل از API **عمومی** (بدون ورود) خوانده می‌شود. با ورود به «آپتل من»، بسته‌های ویژه‌ی ۳۰ روزه با تخفیف و هدیه‌ی نصب (۵ گیگ) نمایش داده می‌شود که در فهرست عمومی نیست. این بسته‌ها عمداً **داخل رتبه‌بندی نمی‌آیند**؛ به‌جایش کارت اطلاعاتی «قیمت‌های ویژه با ورود» در بخش **نکات مهم اپراتورها** نمایش داده می‌شود (نمونه‌ها از ضمیمه‌ی پنل مشترکین به‌روز نگه داشته می‌شوند). این پرچم (`personalized`) برای هر ارائه‌دهنده جداست — فقط جایی فعال است که قیمت واقعاً به ورود وابسته باشد.

## راه‌اندازی GitHub Pages (۲ دقیقه)

1. مخزن را fork یا push کنید (پوشه‌ی `.github/` حتماً بیاید).
2. در Settings → Pages، **Source** را روی **GitHub Actions** بگذارید.
3. push به `main` → workflow «Deploy to GitHub Pages» خودش build و منتشر می‌کند.
4. اگر مخزن شما `USERNAME.github.io` نباشد، سایت از `/نام-مخزن/` سرو می‌شود — workflow به‌طور خودکار `basePath` را ست می‌کند؛ کاری لازم نیست.

### اجرای محلی

```bash
npm install        # یا bun install
npm run dev        # http://localhost:3000
npm run lint
```

### به‌روزرسانی داده‌ها

- **خودکار (روزانه ساعت ۰۷:۰۰ تهران در GitHub Actions):** سامانتل، آپتل و صفحه‌ی جایگزین همراه اول (`mci.ir`)
- **دستی از داخل ایران (به‌دلیل مسدودبودن سرورهای خارج ایران):** فروشگاه کامل همراه اول (`shop.mci.ir`)، ایرانسل و رایتل (همراه و مودم)

```bash
npm run update:iran                              # بروزرسانی همزمان همراه اول، ایرانسل و رایتل از داخل ایران
node update/fetch-providers.mjs                  # همه (شامل خودکارها)
node update/fetch-providers.mjs --only samantel  # فقط سامانتل
node update/fetch-providers.mjs --only aptel     # فقط آپتل
node update/fetch-providers.mjs --only irancell --input products.json  # یا فایل HAR/JSON ذخیره شده
```

workflow «Refresh provider data» هر روز ۰۷:۰۰ تهران اجرا می‌شود؛ ارائه‌دهنده‌هایی که از خارج ایران قابل دسترس نیستند وضعیت قبلی خود را نگه می‌دارند تا وقتی که [داوطلبان داده را اضافه کنند](DATA.md).

## ساختار

```
src/app/                    ← Next.js 16 (App Router) — صفحه‌ی تکی RTL فارسی
src/components/baste-yab/   ← کارت بسته، جدول مقایسه، پنل فیلتر و مقایسه‌ی کنار هم
src/lib/providers.ts        ← رجیستری ارائه‌دهنده‌ها، تشخیص محدودیت‌ها + موتور رتبه‌بندی
src/data/providers/         ← داده‌ی JSON هر ارائه‌دهنده (خروجی fetch-providers)
update/fetch-providers.mjs  ← آداپتورهای استخراج (بدون وابستگی)
.github/workflows/          ← pages.yml (build+deploy) · update-data.yml (refresh روزانه)
public/fonts/               ← فونت استعداد و وزیرمتن (self-hosted — بدون نیاز به اینترنت خارجی)
```
