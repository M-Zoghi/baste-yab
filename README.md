# بسته‌یاب — مقایسه زنده‌ی بسته‌های اینترنت ایران

[LIVE SITE → GitHub Pages](https://YOUR-USER.github.io/YOUR-REPO/) ·
[راهنمای داده‌ها (DATA.md)](DATA.md)

مقایسه‌ی بسته‌های اینترنت ارائه‌دهنده‌های ایرانی بر پایه‌ی **تومان بر گیگابایت** — با
رتبه‌بندی بهترین→بدترین، فیلتر (ارائه‌دهنده، نوع بسته، قیمت، حجم، تخفیف)، کلید مالیات
۱۰٪ و تفکیک **اینترنت ثابت / همراه**. داده‌ها مستقیماً از سایت رسمی هر ارائه‌دهنده
خوانده می‌شوند؛ هیچ عددی دستی نیست.

| ارائه‌دهنده | دسته | منبع |
|---|---|---|
| همراه اول | همراه | ✅ API فروشگاه رسمی `shop.mci.ir/api/search/v1/products?category=19` (تازه‌سازی دستی از داخل ایران) + جایگزین خودکار `mci.ir/internet-plans` |
| سامانتل | همراه (اپراتور مجازی + TD-LTE) | ✅ API عمومی (به‌روزرسانی خودکار روزانه) |
| آپتل | همراه (اپراتور مجازی) | ✅ API عمومی `www.aptel.ir/api/ep/query?scope=public` (به‌روزرسانی خودکار) |
| ایرانسل | همراه | 🔶 JSON عمومی `irancell.ir/e/products/…` (به‌روزرسانی دستی از داخل ایران) |
| رایتل / مخابرات / آسیاتک | — | ⏳ در انتظار داده — [چطور کمک کنید](DATA.md) |

### قیمت عمومی در برابر قیمت مشترک

قیمت‌های آپتل از API **عمومی** (بدون ورود) خوانده می‌شود. با ورود به «آپتل من»،
بسته‌های ویژه‌ی ۳۰ روزه با تخفیف و هدیه‌ی نصب (۵ گیگ) نمایش داده می‌شود که در فهرست
عمومی نیست. این بسته‌ها عمداً **داخل رتبه‌بندی نمی‌آیند**؛ به‌جایش کارت اطلاعاتی
«قیمت‌های ویژه با ورود» بالای فهرست نمایش داده می‌شود (نمونه‌ها از ضمیمه‌ی پنل
مشترکین به‌روز نگه داشته می‌شوند). این پرچم (`personalized`) برای هر ارائه‌دهنده
جداست — فقط جایی فعال است که قیمت واقعاً به ورود وابسته باشد.

## راه‌اندازی GitHub Pages (۲ دقیقه)

1. مخزن جدیدی بسازید و این پروژه را push کنید (پوشه‌ی `.github/` حتماً بیاید).
2. در Settings → Pages، **Source** را روی **GitHub Actions** بگذارید.
3. push به `main` → workflow «Deploy to GitHub Pages» خودش build و منتشر می‌کند.
4. اگر مخزن شما `USERNAME.github.io` نباشد، سایت از `/نام-مخزن/` سرو می‌شود —
   workflow به‌طور خودکار `basePath` را ست می‌کند؛ کاری لازم نیست.

### اجرای محلی

```bash
bun install        # یا npm install
bun run dev        # http://localhost:3000
bun run lint
```

### به‌روزرسانی داده‌ها

```bash
node update/fetch-providers.mjs                 # همه
node update/fetch-providers.mjs --only samantel # فقط سامانتل
node update/fetch-providers.mjs --only aptel    # فقط آپتل
node update/fetch-providers.mjs --only irancell --input products.json  # از داخل ایران
```

workflow «Refresh provider data» هر روز ۰۷:۰۰ تهران اجرا می‌شود؛ ارائه‌دهنده‌هایی که
از خارج ایران قابل دسترس نیستند وضعیت قبلی خود را نگه می‌دارند تا وقتی که
[داوطلبان داده را اضافه کنند](DATA.md).

## ساختار

```
src/app/                 ← Next.js 16 (App Router) — صفحه‌ی تکی RTL فارسی
src/lib/providers.ts     ← رجیستری ارائه‌دهنده‌ها + موتور رتبه‌بندی (همان منطق اسکریپت)
src/data/providers/      ← داده‌ی JSON هر ارائه‌دهنده (خروجی fetch-providers)
update/fetch-providers.mjs← آداپتورهای استخراج (بدون وابستگی)
.github/workflows/       ← pages.yml (build+deploy) · update-data.yml (refresh روزانه)
public/fonts/            ← وزیرمتن (self-hosted — بدون نیاز به Google Fonts)
```
